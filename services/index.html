기술 사전 협의·시스템 설계

Technical Advance & System Design

공연장·전원·리깅 검토, 장비 대체 검토, 도면·패치·시스템 구성

업무 범위

Technical Advance 기술 검토
공연장 도면, 리깅, 전원, 반입 조건을 사전에 확인하고 셋업 일정 안에서 구현 가능한 계획으로 정리합니다.
Fixture & System Review 장비·시스템 검토
요청 장비 리스트를 현장 인벤토리와 대조하고, 연출 의도를 검토해 대체 기종과 시스템 구성을 제작팀과 합의합니다.
Technical Drawing 기술 도면
조명 플롯, 패치 시트, DMX 유니버스 구성표, 매직 시트, 큐시트, 리깅 포인트·로드 정보를 작성합니다.
Venue Lighting System 공간 조명 시스템
공연장·전시장·상설 공간의 조명 시스템을 설계하고, 무인 반복 운영이 필요한 환경까지 구성합니다. 공연장·공간 조명 시스템 보기
