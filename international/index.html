02 — Touring Abroad

해외로 가는 한국 프로덕션

해외 현장은 재시공이 어렵습니다. 출국 전 시뮬레이션과 프로그래밍을 끝내고, 플롯·패치·큐를 문서로 확정해 현지 스태프와 바로 작업할 수 있게 준비합니다. 장비 해외 반출과 현지 조달 모두 대응합니다.

  • Local Inventory Review
  • Fixture Substitution
  • Technical Rider
  • Plot/Patch Adaptation
  • Show File Adaptation
  • Pre-programming
  • Local Vendor Coordination
