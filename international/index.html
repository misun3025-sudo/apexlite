Touring Abroad

한국 작품의 해외 투어 지원

해외 현장은 재시공이 어렵습니다. 출국 전 시뮬레이션과 사전 프로그래밍, 플롯·패치·큐 문서를 준비하고, 현지 공연장 조건에 맞춰 조정합니다. 장비 해외 반출과 현지 조달 모두 대응합니다.

  • Local Inventory Review
  • Fixture Substitution
  • Technical Rider
  • Plot & Patch Adaptation
  • Show File Adaptation
  • Pre-programming
  • Local Vendor Coordination
